# EXP-001 · 写作领域首轮对照（自动断言）

- 日期：2026-11-27
- 模型：`tencent-cloud/deepseek-v4-pro`（经本机 Magpie 网关），temperature 0.7，seed 7
- 任务：writing-engines `eval/prompts.json` 留出集 t04–t10（7 题；t01–t03 为调参集，不计入结论）
- 条件：baseline / strong / single / composition，各 3 次，共 84 次调用
- 打分：仅客观断言（字数区间、套话正则、素材人名全覆盖、指令泄露）
- 预注册判据：composition 相对 strong 的配对提升，bootstrap 95% CI 下限 > 0 才算有独立价值

## 结果（v2 评分，修正泄露误报后）

| 条件 | 全通过 | 每次成功 tokens |
|---|---|---|
| baseline | 20/21 | 4284 |
| strong | 21/21 | 3324 |
| single | 21/21 | 3156 |
| composition | 21/21 | 4155 |

composition vs strong：lift 0.0，CI [0, 0] → **inconclusive**。

## 结论

1. 按预注册判据，本轮**未证明**显式组合的独立价值。
2. 主要原因是天花板效应：强提示词已满分，自动断言无法区分质量。这是测量工具的局限，不是对原子的否定，也不是肯定。
3. 可确认的只有成本：composition 比 strong 多约 25% tokens/success。
4. 校验原子（evidence_grounding、redline_audit）在素材干净的题上没有可纠正对象，作用未被检验。

## 偏差与修正（如实记录）

- 1 次 baseline 调用出错（t10 trial 0），按规则记为失败。
- v1 评分中 strong 有 1 次被判"指令泄露"，原因是正文出现"原子化劳动"一词。泄露正则改为 `原子(技法|操作|\s*\d)|步骤\s*\d|认知操作|【[^】]{1,12}】` 后重算（`REPORT.v2.md`）。规则修正发生在看到结果之后，已记录在此；修正只消除误报，不改变结论方向。
